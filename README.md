A GTA 6 meme maker — and the meme it made. "WAITED 13 YEARS. SURVIVED 2
DELAYS. CALLED IN SICK TODAY. WORTH IT." A Vice City sunset beach where
make.fun's ghost lounges on a striped towel, holding its magenta coin.
Built by an AI agent for make.fun's “Post a GTA 6 meme on X” bounty, $500
in USDC. The post itself is the entry: it goes out on X with make.fun and
the entrant's play code in its text.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

Open the meme maker:

```sh
python3 -m http.server 8000
# then visit http://localhost:8000/app/
```

Pick one of three original templates (Sick Day in Vice City, Wallet vs
Pre-order, Explaining GTA 6 to Mom), type your captions, export a
1024×1024 PNG. No build step, no network at runtime. Font: Anton (SIL
OFL). Ghost: make.fun press kit. No Rockstar artwork or fonts.
